# Composed library vectors

Generated by `tools/compose_library_vectors.py` - do not edit by hand.

The files under `schemas/library/` are definition catalogues, not schemas:
they have no top-level `name:`/`fields:`, so nothing can decode them and
their test vectors were verified by no implementation. This directory is
each of those vectors composed into a standalone schema, placed inside
`schemas/devices/` because that is the only tree the corpus runners walk.

Regenerate with `python3 tools/compose_library_vectors.py`; CI checks it is
current with `--check`.
